# Pandas-Input-Output

Esse repositório contém um notebook que demonstra operações de entrada e saída de dados com a biblioteca Pandas em Python.
O objetivo é mostrar como ler e gravar dados em diferentes formatos de arquivo, como CSV, Excel e JSON, e HTML usando as funções nativas do Pandas.

📍 Projeto é de uso pessoal e educacional , desenvolvido através do Curso: Pandas I/O: trabalhando com diferentes formatos de arquivos da @Alura.
